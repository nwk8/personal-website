# Portfolio

This imported React + TypeScript application uses Vite and lives in `my-portfolio/`.
Keep the existing application structure and npm lockfile.

## Run on Replit

Use the **Start application** workflow (the Run button). It runs:

```sh
cd my-portfolio && npm run dev
```

Vite listens on `0.0.0.0:5000` and permits Replit's preview host.
No secrets, database, or external services are required.

## Development commands

From `my-portfolio/`:

- Install locked dependencies: `npm ci`
- Start development: `npm run dev`
- Build for production: `npm run build`
- Lint: `npm run lint`

Production build output is in `my-portfolio/dist/`.
